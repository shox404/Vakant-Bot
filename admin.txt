Вот как можно реализовать логику, при которой после регистрации данные пользователя отправляются администратору для проверки перед его дальнейшим взаимодействием.

### Пример реализации:

#### 1. **Добавление состояния для вакансии**
Создайте новое состояние, чтобы пользователь мог отправить данные о своей вакансии после регистрации.

```python
from aiogram.dispatcher.filters.state import State, StatesGroup

class UserStates(StatesGroup):
    name = State()
    surname = State()
    age = State()
    vacancy = State()  # Новое состояние для описания вакансии
```

#### 2. **Обновление логики регистрации**
После завершения регистрации, добавьте запрос информации о вакансии.

```python
from aiogram import types
from aiogram.dispatcher import FSMContext
from loader import dp
from states.users import UserStates
from data.config import ADMINS  # Список админов

@dp.message_handler(commands=["registration"])
async def get_user_name(message: types.Message):
    text = "Please enter your name:"
    await UserStates.name.set()
    await message.answer(text)

@dp.message_handler(state=UserStates.name)
async def get_user_surname(message: types.Message, state: FSMContext):
    name = message.text
    await state.update_data(name=name)
    await UserStates.surname.set()
    await message.answer("Great! Now, please enter your surname:")

@dp.message_handler(state=UserStates.surname)
async def get_user_age(message: types.Message, state: FSMContext):
    surname = message.text
    await state.update_data(surname=surname)
    await UserStates.age.set()
    await message.answer("Got it! Finally, enter your age:")

@dp.message_handler(state=UserStates.age)
async def get_user_vacancy(message: types.Message, state: FSMContext):
    age = message.text
    await state.update_data(age=age)
    await UserStates.vacancy.set()
    await message.answer("Thank you! Now, please describe your vacancy or job request:")
```

#### 3. **Отправка вакансии администратору**
После получения информации о вакансии, отправьте данные администратору.

```python
@dp.message_handler(state=UserStates.vacancy)
async def send_vacancy_to_admin(message: types.Message, state: FSMContext):
    vacancy = message.text
    await state.update_data(vacancy=vacancy)

    # Получение данных пользователя
    data = await state.get_data()
    name = data.get('name')
    surname = data.get('surname')
    age = data.get('age')

    # Формирование сообщения для администратора
    admin_message = (
        f"New user has registered!\n\n"
        f"Name: {name}\n"
        f"Surname: {surname}\n"
        f"Age: {age}\n"
        f"Vacancy: {vacancy}\n\n"
        f"Approve this user?"
    )

    # Отправка сообщения всем администраторам
    for admin_id in ADMINS:
        await dp.bot.send_message(admin_id, admin_message, reply_markup=get_approval_keyboard())

    # Подтверждение пользователю
    await message.answer("Your data has been sent to the admin for approval. Please wait.")
    await state.finish()
```

#### 4. **Клавиатура для одобрения**
Создайте инлайн-клавиатуру для администраторов, чтобы они могли одобрить или отклонить заявку.

```python
from aiogram.types import InlineKeyboardMarkup, InlineKeyboardButton

def get_approval_keyboard():
    keyboard = InlineKeyboardMarkup()
    keyboard.add(
        InlineKeyboardButton(text="Approve", callback_data="approve_user"),
        InlineKeyboardButton(text="Reject", callback_data="reject_user")
    )
    return keyboard
```

#### 5. **Обработка решения администратора**
Добавьте обработчики для обработки решений администраторов.

```python
@dp.callback_query_handler(lambda c: c.data in ["approve_user", "reject_user"])
async def process_admin_decision(callback_query: types.CallbackQuery):
    decision = callback_query.data
    user_id = callback_query.from_user.id

    if decision == "approve_user":
        await callback_query.message.answer("User has been approved.")
        # Здесь можно отправить сообщение пользователю об одобрении
    elif decision == "reject_user":
        await callback_query.message.answer("User has been rejected.")
        # Здесь можно отправить сообщение пользователю об отказе

    await callback_query.answer()  # Уведомление, что callback обработан
```

---

### Итоговый процесс:
1. Пользователь проходит регистрацию.
2. После регистрации вводит описание своей вакансии.
3. Данные отправляются всем администраторам.
4. Администратор одобряет или отклоняет заявку через инлайн-клавиатуру.
5. Пользователь получает уведомление о результате.
